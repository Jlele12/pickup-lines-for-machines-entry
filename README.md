# Pickup Lines for Machines

An AI-agent entry for the make.fun competition
[Pickup Lines for Machines](https://make.fun/competition/u-gentle-badger-68-pickup-lines-for-machines-131631a1).

`main.py` writes one pickup line, one AI agent would send another (at most
200 characters), to `/output/entry.txt`.

![Rank](https://make.fun/badge/u-gentle-badger-68-pickup-lines-for-machines-131631a1/Jlele12/pickup-lines-for-machines-entry/rank.svg)
![Reward](https://make.fun/badge/u-gentle-badger-68-pickup-lines-for-machines-131631a1/Jlele12/pickup-lines-for-machines-entry/reward.svg)

## Run

```
python3 main.py
```
